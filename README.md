# Video Prompt Studio — الكود ديالك

هاد المجلد فيه **التطبيق كامل، ديالك ١٠٠٪**. تقدر ترفعو فين ما بغيت، تبدل فيه، ولا تبيعو. بلا أي حقوق علينا.

---

## شنو كاين هنا

```
index.html          الصفحة الرئيسية
src/main.ts         المحرك — الأفكار الجاهزة، الخيارات، ومنطق صناعة البرومبت
src/style.css       التصميم (عربي RTL، داكن، مصاوب للتيليفون)
package.json        الحزم المستعملة
vite.config.ts      إعدادات البناء
dist/               ✅ النسخة الجاهزة للريفع — هادي لي كتحتاج فقط
```

**مهم:** المجلد `dist/` هو التطبيق مبني وجاهز. هو ملفات ساكنة (HTML + CSS + JS) — ماكيحتاج لا سيرفور، لا قاعدة بيانات، لا مفتاح API. هادشي علاش الريفع ديالو مجاني فبلايص بزاف.

## ٣ طرق مجانية باش ترفعو (بلا فلوس، بلا كارط بانكية)

### ١. Cloudflare Pages — الأحسن (مجاني للأبد)
1. سير لـ [pages.cloudflare.com](https://pages.cloudflare.com) ودير حساب مجاني
2. ختار **Upload assets** (ماشي Git)
3. رفع المجلد `dist/` كامل
4. سالينا — الموقع أونلاين على `اسمك.pages.dev`

- زيارات بلا حدود، بلا كارط بانكية، بلا حدود شهرية.

### ٢. Netlify Drop — الأسرع (٣٠ ثانية)
1. سير لـ [app.netlify.com/drop](https://app.netlify.com/drop)
2. رفع المجلد `dist/`
3. الموقع أونلاين دغيا على `اسم-عشوائي.netlify.app`
4. دير حساب مجاني باش تحتافظ بيه وتبدل السمية

### ٣. GitHub Pages — إلا بغيت الكود يكون مخزن عندك
1. دير حساب مجاني ف [github.com](https://github.com)
2. صاوب repository جديد (public)
3. رفع ملي كاين ف `dist/` داخلو
4. Settings → Pages → Source: `main` branch → Save
5. الموقع كيولي أونلاين على `اسمك.github.io/اسم-الريبو`

## بغيتي تبدل شي حاجة بيدك؟

كلشي كيتبدل من `src/main.ts`:

- **الأفكار الجاهزة** — قلب على `const PRESETS` وبدل النصوص
- **الستايلات والكاميرات والضو** — قلب على `const GROUPS`
- **قاموس الكلمات السينمائية** — قلب على `const LEXICON`
- **البرومبت السلبي** — قلب على `const NEG_BASE`
- **نصائح الموديلات** — قلب على `const MODEL_NOTE`
- **السمية والعنوان الكبير** — قلب على `<h1>` ف نفس الملف، والسمية ف `index.html`
- **الألوان** — ف `src/style.css` فاللول: `--action` (الأحمر) و `--accent` (الأخضر)

من بعد أي تبديل، خاصك تعاود تبني:

```bash
npm install
npm run build
```

ومن بعد رفع `dist/` من جديد.

## نقطة مهمة على AI

هاد التطبيق **ماكيعيطش على أي AI** — هو محرك مبني على قواعد التصوير السينمائي الحقيقية، كيخدم كامل داخل متصفح الزائر.

هادشي **ميزة ماشي عيب** فحالتك:
- مجاني تماماً — بلا فلوس على كل استعمال
- سريع بزاف — بلا انتظار
- بلا مفتاح API — وأي موقع عمومي ماقدرش يخبي مفتاح على أي حال

إلا من بعد بغيت AI حقيقي كيعاود يكتب الفكرة، هادشي كيحتاج سيرفور صغير بمفتاح مدفوع.
